# Portfolio de Makhtar Faye

Site statique (HTML, CSS, JavaScript). Aucune installation, aucun `npm`.

## Contenu du dossier

- `index.html` : tout le site (design, animations, texte FR/EN, sons d'effet)
- `covers/` : les 6 couvertures de livres
- `audio/` : `en.mp3` (version anglaise) et `fr.mp3` (version française)
- `documents/` : les PDF des projets
- `cv-makhtar-faye-fr.pdf`, `cv-makhtar-faye-en.pdf` : les deux CV

## Mettre en ligne sur GitHub Pages

1. Dépôt GitHub nommé `Faye-s-portfolio`.
2. Glisser-déposer TOUT le contenu de ce dossier à la racine du dépôt (pas le dossier lui-même, son contenu), puis "Commit changes".
3. Settings > Pages > Source : "Deploy from a branch", branche `main`, dossier `/ (root)`.
4. Après une minute : https://makhtarfaye78-dot.github.io/Faye-s-portfolio/

Pour remplacer un CV ou un PDF : garder exactement le même nom de fichier.

## Tester en local

Double-cliquer `index.html` suffit. Pour un test fidèle : `python3 -m http.server` dans le dossier, puis http://localhost:8000.
